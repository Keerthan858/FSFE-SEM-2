## Description

The College News & Notice Board is a front-end web application that gives students and staff a single place to read college announcements. Notices are organized into categories such as announcements, circulars, events, and important dates, and the latest updates are shown prominently so nothing is missed.

## Key Features

- Responsive layout that works on mobile, tablet, and desktop
- Browse notices by category
- Latest updates section for the newest notices
- Dedicated views for events, circulars, and important dates
- Clean, easy-to-read notice cards

## Tech Stack

- Front-end framework (as covered in the course)
- HTML5, CSS3, JavaScript

## Getting Started
